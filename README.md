# Portfolio

The source of [ftouny.com](https://ftouny.com), Jihad Ftouny's personal
portfolio. It lived at `portfolio.ftouny.com` until 2026-08-30; that address
now redirects to the apex.

Everything lives in [`site/`](site/) — an Astro static site deployed as a
Cloudflare Worker. See [`site/README.md`](site/README.md) for the stack,
structure and deploy commands.

An earlier Angular version of this site was deleted on 2026-08-30 and
survives only in git history.
